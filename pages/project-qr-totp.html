Descriptions of the project, not executed demonstrations. The terminal below reads the same write-up.

Domain
multi-factor authentication and time-based one-time-password validation
Primary stack
Python, QR provisioning, shared-secret encoding, RFC 6238 token generation
Core behavior
provisions a secret into a QR payload, then validates rotating TOTP codes against the same seed
Engineering notes
separates secret enrollment, QR rendering, and verification logic so the auth flow can be tested module by module
