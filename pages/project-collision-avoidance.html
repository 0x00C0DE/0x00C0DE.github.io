Descriptions of the project, not executed demonstrations. The terminal below reads the same write-up.

Domain
robotics safety, autonomous navigation, and obstacle avoidance
Primary stack
Python, perception pipelines, sensor processing, and movement-control logic
Core behavior
analyzes local environment data to identify hazards and steer a mobile platform away from collisions
Engineering notes
combines perception and control layers so navigation decisions can react to changing obstacle geometry in real time
