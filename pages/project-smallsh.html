Unix Small Shell Implementation

Descriptions of the project, not executed demonstrations. The terminal below reads the same write-up.

Domain
systems programming and command interpreter design
Primary stack
C, POSIX process primitives, signal handling, and file-descriptor redirection
Core behavior
tokenizes shell input, launches foreground and background jobs, and tracks process lifecycle events
Engineering notes
exercises fork, exec, waitpid, and signal coordination to reproduce core Unix shell semantics in a compact codebase
