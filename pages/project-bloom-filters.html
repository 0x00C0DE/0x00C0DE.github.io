Why “probably”?

Insert two words. Test a third. Watch shared bits turn into a false positive.

Original teaching schematic, not the linked project. Toy hashes only; this does not assess real passwords. Use public sample words.

Worked example · no JavaScript needed

With 8 bits, cat maps to [0, 1] and dog to [2, 7]. Inserting both sets [0, 1, 2, 7]. The absent word god maps to [2, 1]: both are set, so the answer is “probably present”, a false positive.

Hashes use lowercase ASCII letter codes: sum % size, and sum of each code times its one-based letter position % size. These deliberately simple hashes illustrate collisions, not production quality.
