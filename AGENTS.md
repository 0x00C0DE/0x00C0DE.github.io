# Release workflow

These instructions apply only to `0x00C0DE/0x00C0DE.github.io`. An explicit instruction for the current task takes precedence.

For every owner-requested implementation change, read the [repository release skill](.agents/skills/0x00c0de-release/SKILL.md) before editing and follow it through completion. The default is to start a new feature branch from the latest `origin/main`, verify and push the change on that branch, integrate it into `main`, and verify any affected production deployment in the same task. The owner has authorized these routine release steps for this repository. Report any required approval or release blocker and the last verified state.
