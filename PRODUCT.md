# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Technical peers explore the developer’s work and the implementation details of individual projects.

## Product Purpose

The site is a developer portfolio. Visitors can find the résumé, browse projects, and explore write-ups and demonstrations that explain how the work was done.

## Operating Context

The home page opens a browser-based Unix-like terminal. Visitors can run commands such as `projects` and `cat bloom.txt` or browse the direct project index. File-backed content powers terminal write-ups. The Bitcoin workspace provides an additional entry point for charts and analytics.

## Capabilities and Constraints

The site uses static HTML, native JavaScript, Canvas, and Pretext. GitHub Pages publishes the site. Cloudflare services support selected interactive features. Public discovery must work within the existing authorization boundaries for privileged commands and mutations.

## Product Principles

- Keep projects and the résumé discoverable.
- Ground portfolio claims in project pages, write-ups, and demonstrations.
- Preserve direct navigation and the terminal command interface.
